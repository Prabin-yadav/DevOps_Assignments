# Jira Project & Issue Tracking Assignment

## Objective
This assignment demonstrates how to create a Jira Scrum project, add issues for a simple application workflow, and move a task across the board. The goal is to understand how Jira supports Agile planning and issue tracking.

## Introduction to Jira
Jira is an issue tracking and project management tool used widely in Agile teams. It helps teams organize work into projects, create issues such as stories, tasks, and bugs, and move work items across workflow states on a board.

## Scrum Methodology
Scrum is an Agile framework that organizes work into a backlog and a board with statuses such as To Do, In Progress, and Done. In this assignment, a Scrum project was used so the issues could be tracked visually on the board.

## Jira Commands and Actions Used
Jira work is mostly done through the web interface rather than terminal commands. The key actions performed were:

1. create a Jira Cloud space
2. choose Scrum as the project template
3. create a Story, Task, and Bug
4. open the board view
5. drag the Setup Flask Environment task into In Progress
